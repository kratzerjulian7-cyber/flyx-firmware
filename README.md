# flyx-firmware

Öffentliche Liste der neuesten offiziellen Firmware-Stände, die die Flyx-App liest.

- `versions.json`: Liste im App-Format (`vendor`, `product`, `version`, `date`, `notes`)
- `check.py`: vergleicht neu abgerufene Stände mit der Liste

Wird täglich geprüft und erst nach Freigabe aktualisiert.
